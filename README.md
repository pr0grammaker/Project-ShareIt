## 📌 Описание проекта

**ShareIt** — это сервис совместного использования вещей (шеринг-экономика), где пользователи могут:

- 📦 делиться своими вещами
- 🔍 находить нужные предметы
- 📅 бронировать вещи на определённые даты
- ⭐ оставлять отзывы после использования

Идея проекта — сократить необходимость покупки редко используемых вещей и дать возможность людям эффективно делиться
ресурсами.

---

## 💡 Основная идея

Представьте, что вам нужна дрель для одного ремонта. Покупать её невыгодно, а вот взять у соседа — идеально.  
ShareIt решает именно эту задачу — делает поиск и аренду вещей простой и удобной.

---

## ⚙️ Функциональность системы

### 👤 Пользователи (User)

- Создание пользователя
- Обновление данных
- Получение информации
- Удаление пользователя

---

### 📦 Вещи (Item)

- Добавление новой вещи
- Редактирование (частичное обновление)
- Просмотр по ID
- Просмотр всех вещей владельца
- Поиск по названию и описанию

---

### 📅 Бронирование (Booking) *(будет реализовано позже)*

- Бронирование вещей на даты
- Подтверждение владельцем
- Отмена / отказ

---

### 📝 Запросы (ItemRequest) *(будет реализовано позже)*

- Создание запроса на вещь
- Ответ от других пользователей
- Добавление вещей по запросу

---

## 🧱 Архитектура проекта

Проект построен по принципу **feature-based structure**:

```text
ru.yandex.practicum
├── user        👤 модуль пользователей
├── item        📦 модуль вещей
├── booking     📅 модуль бронирований
└── request     📝 модуль запросов на вещи
```

Каждый модуль содержит:

- Controller
- Service
- Repository
- DTO
- Mapper

## 📡 Основные REST эндпоинты

### 👤 User API

- `POST /users` — создание пользователя
- `PATCH /users/{id}` — обновление
- `GET /users/{id}` — получение по ID
- `GET /users` — список пользователей
- `DELETE /users/{id}` — удаление

---

### 📦 Item API

- `POST /items` — добавить вещь
- `PATCH /items/{itemId}` — обновить вещь
- `GET /items/{itemId}` — получить вещь
- `GET /items` — вещи владельца
- `GET /items/search?text=` — поиск вещей
